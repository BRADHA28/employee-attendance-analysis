
# Employee Attendance Analysis

## 1. Project Overview
This project analyzes employee attendance data to understand attendance patterns, working hours, and department-wise performance.

The project uses Microsoft Excel for data preparation, MySQL for data analysis, and Power BI for dashboard visualization.

## 2. Tools Used
- Microsoft Excel
- MySQL
- Microsoft Power BI
- GitHub

## 3. Dataset Details
- Total Records: 40
- Employees: 10
- Departments: 5
- Attendance Period: January 1–6, 2026
- Attendance Status: Present and Absent

## 4. Project Workflow
1. Created and organized the employee attendance dataset in Excel.
2. Created the employees table in MySQL.
3. Inserted 40 attendance records.
4. Performed data analysis using SQL queries.
5. Imported the dataset into Power BI.
6. Created an interactive attendance dashboard.

## 5. SQL Concepts Used
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- LIKE
- IN and BETWEEN
- Aggregate Functions: COUNT, SUM, AVG, MAX, MIN
- CASE WHEN

## 6. Analysis Performed
- Total attendance records
- Present and absent counts
- Department-wise attendance count
- Department-wise average working hours
- Department-wise total working hours
- Employee-wise total working hours
- Employee attendance summary
- Date-wise attendance count

## 7. Key Insights
- Total attendance records: 40
- Present records: 31
- Absent records: 9
- Highest working hours in a single record: 9
- Lowest working hours: 0

## 8. Power BI Dashboard Features
- Total attendance records card
- Department-wise attendance chart
- Present vs Absent donut chart
- Average working hours by department
- Attendance status comparison by department
- Department slicer for interactive filtering
